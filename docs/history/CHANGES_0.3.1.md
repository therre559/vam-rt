# What to update for 0.3.1 (this also brings you up from 0.2.1, 0.2.2 or the 0.3.0 that did not compile)
1. Unzip over the repo, then run tools\deploy.bat (copies the plugin and the Python scripts).
2. In VaM: plugin Reload on the Person atom.
3. Restart the prompter window (movements now end after a few seconds; names are removed from ARDY prompts).
4. Nothing changes in Voxta.
5. Reactions do nothing until you choose an action for them in the plugin panel (atom, plugin, action).

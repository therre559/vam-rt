# What to update for 0.1.4
1. Unzip over the repo, then run tools\deploy.bat (copies the plugin and the Python scripts).
2. In VaM: plugin Reload on the Person atom.
3. Restart the prompter window (Start_ARDY.bat, or Ctrl+C and run it again) so it picks up the new guard.
4. Import voxta/Copy_of_VAM_Demo_Scene_1_0_7_scenario.json in Voxta (same as the earlier versions), then start a new chat.

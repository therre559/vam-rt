# What to update for 0.2.1
1. Unzip over the repo, then run tools\deploy.bat (copies the plugin and the Python scripts).
2. In VaM: plugin Reload on the Person atom.
3. Restart the prompter window (name scrub and a broader scene-note guard).
4. Nothing changes in Voxta. A new slider "Quiet time before an event (s)" appears in the plugin (default 10).

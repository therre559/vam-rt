# What to update for 0.3.0 (this also brings you up from 0.2.1 or 0.2.2)
1. Unzip over the repo, then run tools\deploy.bat (copies the plugin and the Python scripts).
2. In VaM: plugin Reload on the Person atom. New settings and buttons appear in the plugin panel.
3. Restart the prompter window (movements now end after a few seconds; names are removed from ARDY prompts).
4. Nothing changes in Voxta.
5. Nothing fires unless you wire it: the triggers do nothing until you add actions to them in the plugin's trigger panels.

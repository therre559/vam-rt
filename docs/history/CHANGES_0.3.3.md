# What to update for 0.3.3 (durations; the Senses plugin itself is unchanged from 0.3.2)
1. Unzip over the repo, then run tools\deploy.bat (it copies ardy_stream.py, motion_prompter.py and the BVH Player).
2. Restart BOTH Python windows: the stream (now v20) and the prompter.
3. In VaM reload the BVH Player plugin (only a status warning was added to it).
4. Try the quick checks in docs/DURATIONS.md.

# What to update for 0.2.0
1. Unzip over the repo, then run tools\\deploy.bat.
2. In VaM: plugin Reload on the Person atom.
3. Nothing changes in Voxta or the prompter. Events start OFF.
4. To try them: switch on "Send events", keep Auto-send on, walk the camera in and out, and stare at her for a few seconds.

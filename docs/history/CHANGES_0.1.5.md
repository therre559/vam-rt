# What to update for 0.1.5
1. Unzip over the repo, then run tools\deploy.bat (copies the plugin and the Python scripts).
2. In VaM: plugin Reload on the Person atom.
3. Restart the prompter window (Start_ARDY.bat, or Ctrl+C and run it again) so it picks up the new guard.
4. Import voxta/Copy_of_VAM_Demo_Scene_1_0_8_scenario.json in Voxta (same as the earlier versions), then start a new chat.
5. In the plugin, try Delivery = "Hidden chat message" and set Min seconds between sends to 10 or more.
